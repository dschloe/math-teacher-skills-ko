# Math.skill (한국어 번역 README)

> 원본: [Wholiver/Math.Skill](https://github.com/Wholiver/Math.Skill) 의 `README.en.md` 를 한국어로 옮긴 문서입니다. MIT License, Copyright (c) 2026 Wholiver.
> 이 폴더의 `SKILL.md` 와 `modules/` 는 **원문(영어) 그대로**입니다. 이 스킬은 사용자가 쓰는 언어에 맞춰 답하도록 되어 있어서(원문 "Language Matching Rules"), 한국어로 질문하면 한국어로 답합니다.

> *"문제 하나, 검증된 답 하나."*

**에이전트에 수학 문제를 입력하면, 엄밀하고 단계별로 검증된 풀이가 돌아옵니다.**

산술부터 추상대수까지, Math.skill 은 AI 에이전트에게 규율 있는 수학 작업 흐름을 줍니다. 모든 문제는 분석되고, 모델링되고, 근거를 달아 풀리고, 서로 독립인 여러 방법으로 검증된 뒤에야 최종 답으로 나갑니다.

검증 엔진이 핵심 차별점입니다. 두 가지 이상의 검증 방법을 통과하지 못한 답은 출력되지 않습니다. 문제가 알려진 미해결 문제(골드바흐, 리만 가설 등)라면, 돌파구를 지어내지 않고 솔직하게 말해 줍니다.

## 설치

```bash
npx skills add Wholiver/Math.Skill
```

또는 이 저장소의 `skills/math-skill/` 폴더를 에이전트의 skills 폴더(예: `~/.claude/skills/`)에 복사합니다.

## 할 수 있는 일

| 기능 | 결과물 | 보통의 출력 |
|---|---|---|
| 표준 문제 풀이 | 전체 단계별 풀이 · 대입 검증 · 정의역·경계 확인 | 5~15단계 |
| 증명과 추론 | 논리 구조 · 반례 탐색 · 한정기호 형식 점검 | 10~20단계 |
| 풀이 검토 | 오류 위치 지적 · 고친 유도 · 재검증 | 5~10단계 |
| 문제 출제 | 잘 정의된 문제 · 전체 풀이 · 채점 기준 | 3~5문제 |
| 고등 수학 | 극한·미적분·선형대수·상미분방정식 분석 · 정리의 조건 확인 | 10~25단계 |
| 연구 수준 문제 | 불확실성의 솔직한 표시 · 부분 결과 · 실패한 경로 기록 | 10~30단계 |

## 핵심 장치

### 7단계 추론 흐름

모든 문제는 이 순서를 거칩니다.

| 단계 | 이름 | 하는 일 |
|---|---|---|
| 1 | 문제 분석 | 조건, 목표, 변수, 정의역을 뽑는다. 모호함, 빠진 조건, 오류를 찾는다 |
| 2 | 수학적 모델링 | 방정식, 함수, 집합, 행렬, 확률공간 등 형식적 표현을 만든다 |
| 3 | 방법 선택 | 30가지 이상의 방법(인수분해, 치환, 귀납법, 로피탈 등)에서 최적을 고른다 |
| 4 | 단계별 풀이 | 모든 변형에 근거를 단다. 0으로 나누지 않는다. 연산마다 정의역을 확인한다 |
| 5 | 검증 (아래 참고) | 11가지 검증 방법 중 여러 독립 검증을 적용한다 |
| 6 | 오류 수정 | 검증에 실패하면 위치를 찾고, 되짚고, 고치고, 다시 계산하고, 다시 검증한다 |
| 7 | 최종 답 | 조건, 정확한 꼴, 검증 요약이 있는 명확한 결론 |

### 11가지 검증 방법 (A–K)

이 스킬의 심장입니다. 각 풀이는 최소 2가지 방법을 통과해야 합니다.

| ID | 방법 | 잡아내는 것 |
|---|---|---|
| A | **대입 검증** | 답을 원래 식에 대입한다. 무연근(extraneous roots)을 잡는다 |
| B | **정의역 확인** | 분모 0, 근호 안 음수, 로그의 진수 ≤ 0 등 |
| C | **경계 분석** | 빠뜨린 끝점, 임계점, 매개변수 경계값 |
| D | **역방향 유도** | 거꾸로 원래 조건으로 돌아간다. 되돌릴 수 없는 단계의 오류를 잡는다 |
| E | **수치 표본 검증** | 구체적인 값을 넣어 본다. 부호 오류, 몇 배 틀린 실수를 잡는다 |
| F | **차원 분석** | 단위 불일치, 1보다 큰 확률, 음수 분산 |
| G | **극한과 특수한 경우** | 매개변수 → 0/∞, 퇴화한 경우의 일관성 |
| H | **독립 교차 검증** | 다른 방법으로 다시 푼다. 대수 + 그래프, 해석 + 수치 |
| I | **반례 탐색** | 전칭 주장·증명 시도에서 저차원, 경계, 0인 경우를 찾아본다 |
| J | **형식 논리 점검** | 한정기호 순서(∀∃ 대 ∃∀), 필요조건 대 충분조건, 순환 논증 |
| K | **계산 일관성** | 다시 계산, 행렬 차원 확인, det(A-λI)=0 확인, 전체 확률 = 1 확인 |

### 34개 범주 입력 분류

풀기 전에 문제를 분류합니다.

```
calculation | algebra_simplification | equation_solving | system_of_equations
inequality_solving | function_analysis | geometry | analytic_geometry
trigonometry | sequence | combinatorics | probability_statistics | word_problem | limit
differentiation | integration | multivariable_calculus | linear_algebra
ordinary_differential_equation | complex_analysis | real_analysis
abstract_algebra | topology | number_theory | discrete_math | optimization
mathematical_modeling | proof | counterexample | solution_checking
problem_generation | research_level_problem | ambiguous_or_incomplete
out_of_scope
```

범주마다 식별 특징, 권장 전략, 반드시 확인할 조건, 흔한 오류, 검증 규약, 출력 형식이 따로 있습니다.

### 오류 방지 엔진

가장 흔한 수학 실수를 막는 8가지 영역의 안전장치입니다.

| 영역 | 핵심 안전장치 |
|---|---|
| **대수** | 인수분해 후 다시 전개 · 0으로 나누기 확인 · 제곱한 뒤 근 검증 |
| **부등식** | 음수를 곱하면 부호 반전 · 변수가 든 식은 경우 나누기 |
| **함수** | 먼저 정의역 구하기 · 미분 불가능한 점 확인 · 임계점과 극값 구분 |
| **기하** | 눈대중에 기대지 않기 · 정리의 조건 밝히기 · 보조선 설명하기 |
| **확률** | 표본공간 정의 · P∈[0,1] 확인 · 전체 확률 = 1 · 분산 ≥ 0 |
| **미적분** | 로피탈 조건 확인 · 테일러 나머지 항 명시 · +C 붙이기 · 수렴 확인 |
| **선형대수** | 행렬 차원 확인 · Av=λv 검증 · A=PDP⁻¹ 확인 |
| **추상 수학** | 정의의 완전성 확인 · 한정기호 순서 · 잘 정의됨(well-definedness) |

### 어려운 문제 규약

경시대회 문제, 연구 수준 질문, 미해결로 의심되는 문제를 만났을 때:

1. **분류** — 표준 교과서 문제인가? 대회 문제인가? 알려진 미해결 문제인가? 빠진 조건이 있는가?
2. **검색** — 알려진 정리, 비슷한 문제, 미해결 여부
3. **비슷한 것을 찾았다면** — 접근법을 참고하되 독립적으로 다시 유도하고 각 단계를 검증
4. **아무것도 못 찾았다면** — 제1원리에서 출발: 정의를 쓰고, 분해하고, 간단한 경우를 시도하고, 반례를 구성하고, 귀납하고, 변환하고, 보조정리를 세운다
5. **미해결일 수 있다면** — 검증된 사실 / 추측 / 수치 증거 / 실패한 접근을 분명히 구분해 밝힌다. 빈틈없고 공개적으로 검증 가능한 완전한 증명이 없으면 돌파구를 이뤘다고 주장하지 않는다.

```

├── SKILL.md                           ← 핵심 정의 (693줄)

│   ├── classification.md              ← 34개 범주 입력 분류 (1,567줄)
│   ├── reasoning_workflow.md          ← 7단계 추론 흐름
│   ├── verification_engine.md         ← 검증 방법 A–K (598줄)
│   ├── error_prevention.md            ← 8개 영역 오류 방지
│   ├── search_policy.md               ← 검색 전략과 윤리
│   ├── hard_problem_protocol.md       ← 어려운 문제 규약
│   ├── higher_math_modules.md         ← 고등 수학 모듈 8개
│   ├── interaction_policy.md          ← 상호작용 시나리오 18개 (611줄)
│   └── output_templates.md            ← 출력 형식 템플릿 6개
```

## 교사용으로 쓰는 법 (번역자 메모)

이 부분은 원문이 아니라 번역자가 덧붙인 활용 제안입니다.

- **정답 검산**: 출제한 문제와 답안을 붙여 넣고 "풀이 검토" 모드로 오류를 찾게 한다. 다만 스킬이 낸 결과도 최종 판단은 교사가 한다.
- **문제 출제**: "중3 이차방정식 문제 5개를 풀이와 채점 기준까지" 처럼 요청한다. 숫자는 코드로 한 번 더 검산하는 것을 권한다.
- **풀이 설명**: "교사처럼 가르치는 모드(Teach-like-a-teacher mode)"로 요청하면 단계마다 "왜 되는지"를 설명한다.
