# Manim 교육용 애니메이션 영상

## 빠른 목표

사용자가 한국어로 요청한 내용을 바탕으로 실행 가능한 Manim 작업 묶음(대본, 장면 구성, 코드, 렌더 명령)을 만들고, 핵심 교수 설계 선택을 설명한다.

## 먼저 확인할 최소 정보

- 주제와 대상: 무엇을, 누구에게 설명하는가 (예: 중3 학생, 고2 수학Ⅱ, 대학교 1학년)
- 길이와 속도: 전체 길이, 빠르기, 장(章) 구분 여부
- 화면 스타일: 칠판풍, 단순한 선 그림, 색 강조를 쓸지 여부
- 수학·코드 내용: 공식, 의사코드, 예시 데이터

사용자가 알려 주지 않았다면 합리적인 기본값을 정하고, 어떤 가정을 했는지 밝힌다.

## 작업 순서

1. 사용자의 요청을 교육용 대본으로 바꾼다 (구조화된 문단: 도입 - 핵심 - 정리).
2. 대본의 각 문단에 장면 구성(화면 목표, 핵심 애니메이션, 나레이션 요점)을 붙인다.
3. 시각 언어(색, 글자 크기, 정렬, 강조 규칙)를 정하고 끝까지 일관되게 유지한다.
4. Manim 코드를 만든다 (Scene 구조가 분명하고 변수 이름이 뜻을 드러내게).
5. 렌더 명령과 권장 옵션(해상도, fps, 화질)을 준다.
6. 스크립트로 나레이션 음성을 만들고, 필요하면 자막(SRT)도 함께 만든다.
7. 스크립트로 영상과 음성을 합치고, 필요하면 자막을 영상에 넣는다.
8. 스크립트로 별도 썸네일 이미지를 만든다 (공유·배포용).
9. 핵심 교수 설계 선택(왜 이런 장면 나눔·전환·강조를 썼는지)을 짧게 설명한다.

## 교육용 대본 템플릿

입으로 읽기 좋은 짧은 문장, 짧은 호흡으로 쓴다.

1. 도입: 문제·현상·동기 (1~2문장)
2. 정의: 핵심 개념 (1~3문장)
3. 원리: 핵심 단계 또는 유도 (2~5단계로 나눔)
4. 예시: 구체적인 예 하나로 확인
5. 정리: 핵심을 한 문장으로 되짚기

## 장면 나눔의 알맞은 크기

- 한 장면 묶음은 15~30초로, 정보가 너무 빽빽해지지 않게 한다.
- 유도의 각 단계와 핵심 결론은 각각 별도 장면으로 만든다.
- 한 장면에는 주요 시각 요소를 최대 1~2개만 둔다.

## Manim 코드 규칙

- `Scene` 또는 `MovingCameraScene`을 쓰고, 장면 하나를 재사용하기 쉽게 유지한다.
- 복잡한 애니메이션은 작은 함수로 나눈다 (예: `show_definition()`).
- `VGroup`으로 요소를 묶어 정렬과 간격을 통일한다.
- `FadeIn/FadeOut/Transform/ReplacementTransform`으로 논리의 전환을 보여 준다.
- 수식은 `Tex/MathTex`로 써서 수학 조판을 일관되게 하고, 한글 설명문은 `Text`를 쓴다.

## 기본 기술 설정

- 해상도: 1920x1080
- fps: 30
- 렌더 화질: 기본 `-qh`
- 출력: MP4

## 시각·속도 기본값

- 기본색: 파랑 또는 주황 중 하나를 골라 끝까지 유지
- 강조색: 밝은 노랑 또는 빨강 (핵심 결론에만)
- 여백: 화면 가장자리 10~15%를 안전 영역으로 비운다
- 나레이션 속도: 분당 120~150자 (원문 기준이며 중국어 글자 수다. 번역자 주: 한국어는 같은 속도라도 글자 수가 달라지므로 완성된 음성을 직접 들어 보며 조정한다)

## 스크립트 우선

음성 생성, 합성, 썸네일은 `scripts/` 아래 스크립트로 처리하고, 사용자가 명령을 직접 쓰게 하지 않는다.

사용할 수 있는 스크립트:

- `scripts/tts_generate.py`: 나레이션 텍스트를 음성으로 변환 (edge-tts). `--subs-output subs.srt`로 자막도 출력
- `scripts/concat_audio.py`: 여러 나레이션 조각을 합침 (ffmpeg concat)
- `scripts/mux_av.py`: 영상과 음성을 합침 (ffmpeg). `--subs subs.srt`로 자막을 넣음
- `scripts/make_cover.py`: 16:9 썸네일 이미지 생성 (Pillow)
- `scripts/pipeline.py`: 음성, 합성, 썸네일을 한 번에 실행
  - 선택 옵션: `--dry-run`은 명령만 출력하고 실행하지 않음, `--verbose`는 실행 명령을 보여 줌, `--log-file`은 명령 목록을 기록(기본은 덮어쓰기), `--append-log`는 이어서 기록
  - 자막 옵션: `--subs-output subs.srt`(TTS로 자막 생성), `--subs subs.srt`(이미 있는 자막 사용)

스크립트가 의존성이 없다고 알려 주면 해당 의존성(edge-tts, ffmpeg, Pillow)을 설치하라고 안내한다.

번역자 주: 한국어 나레이션을 만들려면 edge-tts의 한국어 음성(예: `ko-KR-SunHiNeural`)을 지정하는지 확인한다. 스크립트의 기본 음성은 원본 저자 기준이라 한국어가 아닐 수 있으므로, `scripts/tts_generate.py`의 옵션을 확인하고 필요하면 음성을 지정한다.

예시(권장):

```bash
python scripts/pipeline.py \
  --video manim.mp4 \
  --tts-file narration.txt \
  --subs-output subs.srt \
  --cover-title "이차함수 꼭짓점 꼴" \
  --cover-subtitle "60초 완성" \
  --output output.mp4
```

## 썸네일 규격과 권장 사항

- 비율: 16:9
- 크기: 1920x1080 (본 영상과 동일)
- 글자 위계: 제목 1줄 + 부제 1줄(선택)
- 구성: 왼쪽에 큰 제목, 오른쪽에 그림이나 핵심 공식
- 색: 기본색 + 강조색, 주요 색은 3가지를 넘기지 않는다
- 내보내기: PNG, 선명도 유지

## 사용자가 요청할 만한 문장 예시

- "Manim으로 이차함수 꼭짓점 꼴을 설명하는 60초 영상을 만들어 줘."
- "행렬 곱셈을 설명하는 교육 애니메이션을 깔끔한 화면으로 만들어 줘."
- "이 개념을 고등학생에게 설명하는 Manim 코드와 렌더 명령을 줘."
- "수능 수학 삼각함수 문제의 풀이 과정을 단계별로 보여 주는 영상 대본을 써 줘."

## 출력 형식 권장

- 먼저 대본과 장면 구성을 준다.
- 그다음 바로 실행할 수 있는 Manim 코드를 준다.
- `scripts/pipeline.py` 사용법을 우선 안내한다.
- 조각별 합성이나 별도 흐름이 필요하면 해당 스크립트(`tts_generate.py`/`concat_audio.py`/`mux_av.py`) 사용법을 준다.
- 썸네일 디자인 제안과 내보내기 규격을 준다 (`make_cover.py`에 대응).
- 마지막으로 Manim 렌더 명령과 옵션 설명을 준다.
- 사용자가 나레이션을 원하면 녹음용 대사와 자막(SRT)을 함께 준다.

## 자주 쓰는 개선 포인트

- 중요한 개념은 색, 굵기, 확대로 강조한다.
- 애니메이션은 조금 느린 쪽이 낫다. 여백을 두어 이해할 시간을 준다.
- 식의 유도는 한 번에 쌓지 말고 단계별로 나타낸다.
- `Wait()`로 학생이 생각할 시간을 준다.

## 품질 점검표

- 논리 순서가 분명하고 장면 사이 전환이 자연스러운가
- 글이 너무 빽빽하지 않고 화면이 답답하지 않은가
- 핵심 단계를 색이나 애니메이션으로 강조했는가
- 렌더 설정이 목표 플랫폼(수업 화면, 유튜브 등)에 맞는가
